# HWH Extensions GreasyFork Artifacts

Публичное зеркало содержит собранные `.user.js` и `.meta.js` для каналов с включённой публикацией.
Исходники живут в приватном репозитории, потому что публичная витрина не обязана показывать всю кухню.

GreasyFork синхронизируется с raw URL файлов из этой ветки.
